# Caemble CAE worker

CAE runs built Measurements received through the remote job WebSocket or the
local CLI bridge. From this directory, `poetry install --with dev` installs
runtime and test tools.

Before a Solver change, read [AGENTS.md](AGENTS.md) and the complete
[Solver development contract](../../../docs/development/solver-development.md).
See [CAE development](../../../docs/development/cae.md) for kernel ownership and
[Solver authoring](../../../docs/authoring/solver.md) for the workflow.
