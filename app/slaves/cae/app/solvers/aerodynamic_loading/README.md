# 날개가 바람에서 힘을 얻는 계산

`entry.py`는 ABI 연결, `domain.py`는 입력 정리, `formulation.py`는 수치 계산,
`outputs.py`는 결과 포장만 담당한다. 다른 Solver의 내부 상태나 Python 모듈은
읽지 않는다. 단위와 입력 선언, 실행 가능한 터빈 예제는 Catalog가 관리한다.

날개를 반경별 작은 단면으로 나누고 다음 순서로 계산한다.

1. 구조 해석이 준 위치·속도·방향으로 날개에서 보는 상대 바람을 구한다.
2. 유입각 하나를 미지수로 두고, 단면의 양력·항력과 공기 운동량의 변화가
   일치하는 각도를 Brent 방법으로 찾는다. 이것이 BEM이다. Prandtl 보정은
   허브와 끝단의 유한한 날개 수를 반영하고, Buhl 보정은 큰 축 유도계수를 연결한다.
3. 바람의 변화가 유도속도에 즉시 반영되지 않는 현상은 Øye의 두 지연 방정식으로
   계산한다. 구간별 일정 입력의 해를 지수함수로 구하므로 작은 시간상수 때문에
   명시적 Euler 적분이 발산하는 문제를 피한다. 입력 변화는 구간 중간값으로 근사한다.
4. 유도속도로 보정한 상대 바람과 polar 표에서 양력·항력·단면 모멘트를 계산한다.
   각 단면이 대표하는 길이를 곱하고, 이를 전역 절점 힘과 모멘트로 변환한다.

방향 행렬의 열은 `[span, chord, normal]`이며 local→world 변환이다.
회전축이 +X이고 날개가 +Z를 향할 때 chord는 회전 진행 방향인 −Y,
normal은 바람의 진행 방향인 +X다. 명령 pitch와 탄성 비틀림은 구조 해석의
방향 행렬에 이미 들어 있다. 이 모듈은 단면의 공력 twist만 추가한다.
양의 feather pitch는 leading edge를 바람 쪽으로 돌리는 −span 회전이다.
따라서 방향 행렬에서 읽은 +span 회전각의 부호를 바꿔 공력 pitch로 사용한다.

`aerodynamicOffsets`는 기준 절점에서 공력 작용점까지의 local 거리를 담는다.
현재 방향으로 회전시킨 거리 d에 대해 작용점 속도는 `v + ω×d`이다.
그 위치에서 힘 F를 계산하고, 절점 모멘트에 `d×F`를 더한다. 힘뿐 아니라
`F·v + M·ω`의 일률도 보존된다. 기준 형상에서 OpenFAST의 downwind
`BlCrvAC`, 회전 반대 방향의 `BlSwpAC`는 `[0, -BlSwpAC, BlCrvAC]`로 대응한다.

wind 표는 시간에 대해 선형 보간하고 표 밖에서는 끝 값을 유지한다. Polar도
선형 보간한다. 충분한 받음각 범위의 polar를 제공해야 한다. 단면 반경은 허브와
끝단 사이에 있어야 한다. 허브/끝단 자체에서는 Prandtl 극한 `a=1, a'=0`을
사용한다. 축 상대속도가 0이어도 회전과 polar 때문에 단면 힘이 남을 수 있다.
끝점을 포함하는 선형 하중 적분은 끝점에 이웃 간격의 절반, 내부 점에 양옆
간격 합의 절반을 대표 길이로 준다. Øye의 로터 평균에는 반경×대표 길이로
가중한 면적 평균을 사용한다. OpenFAST의 kernel 기반 평균과는 다른 이산화다.
현재 BEM은 정방향 축 유입과 정방향 회전을 대상으로 한다. 역류 운전, 동적 실속,
skew wake, tower shadow와 난류 생성은 이 구현의 모델 범위 밖이다.
`rotorAxis`는 전역 좌표에 고정한 기준 회전축이다. 날개 단면의 실제 방향·속도는
반영하지만, 나셀의 yaw 동작이나 타워의 큰 기울기에 따라 원판 축을 갱신하는
모델은 아니다. 정렬된 고정식 터빈에서 이 근사가 적절한지 별도로 확인한다.

여러 연성 반복은 같은 채택 checkpoint에서 시작한다. 계산 중 입력 배열은
   수정하지 않으며, 반환하는 task 상태에는 마지막 시각과 두 유도속도 상태가 담긴다.
같은 창을 다시 계산한다고 wake의 물리적 시간이 여러 번 진행되지 않는다.

직접 계산 API는 `aerodynamic_response`, 단면 API는 `bem_section`이다.
검증은 `tests/test_wind_physics.py`에서 저유도/고유도 운동량 평형,
Øye 상태 방정식의 독립적인 행렬 지수 해, 양의 피치 방향, 끝점 하중,
작용점 이동의 힘·모멘트·일률 보존, 재시작과 실제 StateStore commit을 확인한다.
