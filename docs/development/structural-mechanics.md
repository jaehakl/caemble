# CSG 기반 구조해석 구현

공개 실행 경로는 CSG 형상, 재료, 물리 조건과 공간 해상도에서 체적 계산
모델을 생성한다. 사용자는 절점 번호, 요소 연결 배열이나 단면 행렬을 작성하지
않는다. 정확한 입력·출력 선언과 실행 가능한 예제의 정본은 SQLite Catalog다.
이 문서는 계약을 복제하지 않고 코드의 계산 의미와 검증 경로를 설명한다.

## 형상에서 계산 모델까지

브라우저와 CLI는 같은 형상 평가기를 사용한다. 화면 미리보기와 해석 준비의
정밀도는 분리된다. 해석 준비는 곡면과 기존 Fiber 함수를 원래 정의에서
조밀하게 다시 평가한다. 미리보기의 성긴 점을 보간하지 않는다. 평가 프로파일과
실제 표본은 canonical Geometry의 식별자에 반영된다.

현재 해석 준비 프로파일은 각도 방향 최소 128분할, Fiber 경로 최소 512분할을
사용하고 원래 정의의 더 조밀한 설정은 유지한다. 이는 원래 함수의 유한 표본
근사이며 체적 요소 크기와 별개다. 체적 메쉬 수렴만으로 곡면의 기하 근사 오차까지
없어지는 것은 아니다. 프로파일 변경은 브라우저·CLI 공통 평가기에서 수행한다.

`domain.py`는 선택한 CSG root를 공통 Geometry 서비스에 전달한다.
Boolean 평가는 그 계층에서 수행하며, `methods/mesh`의 Netgen adapter가
닫힌 경계 안을 양의 체적을 가진 선형 사면체로 채운다. 요소 종류 선택은
Solver 내부 결정이다. 경계 삼각형을 체적 요소로 간주하지 않는다.

지지·하중·관측은 Geometry 면 그룹을 참조한다. Boolean 이후 남은 경계의
`(rootId, sourceNodeId, surfaceIndex)` 출처로 면 그룹을 해석하므로 공간
해상도가 달라져도 선택의 뜻이 유지된다. 완전히 잘려 나간 면을 조건의
대상으로 지정하면 오류다. 접합한 재료 root는 공동 경계를 갖고, 접촉만 하는
부품은 별도의 절점과 체적 영역을 유지한다. 적층은 층마다 실제 CSG 체적,
재료와 재료 방향을 지정한 접합 모델이다.
공동 경계의 두 재료 쪽은 반대 외향 법선을 갖는다. 같은 경계 삼각형을
공유하더라도 압력·접촉 조건은 선택한 재료 쪽의 방향을 사용한다.

평면 공동 경계는 두 부품의 겹치는 영역과 노출 영역을 나누어 함께 삼각화한다.
부분적으로 걸친 면, 경계에 닿는 접합, 구멍과 서로 다른 경계 분할도 원래 면의
출처를 유지한다. 같은 체적을 두 재료가 차지하거나 세 영역 이상이 한 경계의
면적을 공유하는 잘못된 모델은 거절한다.
모서리나 점만 닿는 부품은 접합 면적이 없으므로 그 절점을 임의로 묶지 않고
진단 오류를 낸다. 실제 공동 면들이 만나는 세 재료의 T자 경계는 허용한다.

곡면 공동 경계에는 제한이 있다. 양쪽 canonical 삼각화가 일치해야 하며,
비일치 곡면을 공통 재삼각화하는 경로는 없다. 이런 형상은 Netgen 생성 또는
후속 위상 검증에서 실패할 수 있다. 수기 연결 배열로 우회하지 않는다.

캐시는 형상 hash, root 선택, 단위, 표현, 메셔 버전과 메쉬 프로파일로
구별한다. 열린 경계, 퇴화 요소, 재료 영역 오류와 정밀화 실패를 수기 메쉬
입력으로 우회하는 공개 경로는 없다. Netgen의 버전과 배포 고지는
[methods/mesh](../../app/slaves/cae/app/methods/mesh/)에서 관리한다.
경계 및 체적 요소 수의 사전 예산 검사, 정밀화 횟수 제한과 실제 생성량 검사를
거치며 너무 작은 해상도는 자원 초과 오류로 거절한다.

## 자유도, 하중과 연결

`StructuralModel`의 배열 stride는 기존 수치 구현과 공유하지만 물리 체적
절점에는 병진 세 자유도만 활성화한다. 회전이 필요한 부착 면은 내부 기준점을
만들고 그 면의 물리 절점에 분포된 강체 구속을 연결한다. 기준점은 면적 중심에
있으며 화면의 체적 메쉬에는 포함하지 않는다.

강체 연결과 회전 연결은 큰 penalty 강성으로 흉내 내지 않고 변환행렬로
종속 자유도를 제거한다. 편심을 가진 연결은 증분에서
`du_slave = du_master + dtheta_master × r`를 만족한다. 힘을 변환행렬의
전치로 모으므로 모멘트와 가상일도 전달된다. 부착 면의 중복, 구속 순환,
종속 운동에 대한 모순된 지지 또는 지지 부족을 인공 강성으로 숨기지 않는다.

면의 총 힘·모멘트는 면적 가중 최소 제곱 분포로 절점력에 변환한다. 지정한
기준점에 대한 합력과 합모멘트가 보존된다. traction은 면적에 적분하고,
양의 압력은 외향 법선의 반대 방향으로 작용한다. 중력은 생성된 체적 질량으로
적분한다. 초기 운동은 지정한 부품의 물리 위치에서 `v + omega × r`로 만든다.

회전 연결의 자유 상대각은 여러 회전을 연속해서 셀 수 있는 내부 좌표다.
공개 자세는 회전행렬이고 회전 벡터는 principal logarithm이므로 그 크기가
여러 바퀴의 누적 회전수를 뜻하지 않는다. 유한회전 탄성 스프링은 보존적인
단일축 상대각이 필요하다. 자유로운 다축 공간 회전 벡터의 한 성분에 임의
탄성 스프링을 붙이는 조합은 거절한다.
회전자 조립체는 task당 하나를 선언한다. 여러 회전자 정의를 한 task에 넣어
앞선 조립체의 제어·초기화를 덮어쓰는 모델은 거절한다.
서로 다른 회전자 부착 대상은 서로 다른 부품이어야 한다. 같은 부품의 재료
방향이나 초기 운동을 겹쳐 지정해 선언 순서에 따라 덮어쓰는 경우도 거절한다.

## 체적 요소와 재료

`continuum.py`는 보간함수의 공간 미분으로 변형률을 얻고, `materials.py`의
재료 법칙으로 응력을 계산한다. 응력을 다시 적분한 내력과 그 일관된 접선을
`formulation.py`에서 희소 전역 행렬에 조립한다. 공학 변형률과 응력의 Voigt
순서는 `xx, yy, zz, xy, yz, xz`다.

작은 변형률의 등방 탄성, 직교이방 탄성, J2 등방경화를 사용한다.
J2 return mapping은 확정된 단계의 이력에서 시작하며 Newton 후보가 실패하면
trial 이력을 버린다. 적층의 재료 방향은 각 실제 체적의 탄성 텐서에 적용한다.
거의 비압축성 거동과 얇은 굽힘에서는 선형 사면체의 locking과 수렴을 별도로
확인해야 한다. 자동으로 혼합 요소나 보·쉘 모델로 바꾸지 않는다.

큰 회전의 체적 탄성 경로는 변위구배의 극분해로 강체 회전을 제거한다.
corotated 작은 변형률 에너지의 미분으로 힘과 접선을 계산한다. 통째로
회전한 물체의 에너지가 증가하지 않아야 한다. 이 경로는 새로운 유한변형률
재료 모델이 아니며 큰 회전과 J2 유한변형 소성을 결합한 모델로 해석하지 않는다.

기존 보·쉘·평면·직접 배열 요소 계산 코드는 내부 수치 회귀를 위해 유지한다.
`tests/structural_fixture.py`가 그 배열 기반 모델을 구성한다. 생산 진입점은
이 fixture를 import하지 않으며 이전 입력 계약으로 자동 연결하지 않는다.

## 해석 종류와 접촉

- 정적 해석은 외력과 내력의 평형을 찾는다. 비선형 이력은 수렴 후에만 채택한다.
- 모달 해석은 기준 탄성 형상의 `K phi = omega² M phi`를 풀고 모드 질량을
  1로 정규화한다. 큰 체적 모델에서는 희소 고유치 계산을 사용한다.
- 주파수응답은 기준 `K, M, C`의 복소 응답을 실수부·허수부로 출력한다.
- 선형 좌굴은 탄성 예비하중의 응력 기하강성에서 양의 임계 하중배수를 찾는다.
  좌굴 이후 거동이나 회전 중 운전점 선형화가 아니다.
- 시간해석은 Newmark 평균가속도법으로 평형을 풀고 실제 시간 좌표를 기록한다.
  안정성이 시간 정확도를 보장하지 않으므로 시간 간격 수렴도 확인한다.

모달·주파수응답은 접촉 없는 탄성 기준상태이며 좌굴도 탄성 소변위 예비하중을
사용한다. 큰 회전 옵션을 켠다고 이 기준상태 해석이 운전점 해석으로 바뀌지는
않는다. 접촉은 면적을 적분한 무마찰 penalty 접촉이며 압입 길이에 비례하는
법선 traction을 양쪽 면에 전달한다. 공간 탐색으로 후보 면을 좁힌다.
마찰 이력, 자기접촉, 균열과 손상은 포함하지 않는다.

## 출력과 기록의 의미

Field는 실제 체적 절점·사면체와 함께 반환된다. 경계면, 재료 영역, 표면 출처,
품질, 지지 절점과 하중 위치를 `domain.metadata`에 담는다. 공식 예제는 이
정보까지 기록하므로 Viewer를 다시 열 때 새로운 메쉬를 만들 필요가 없다.
Viewer는 와이어프레임, 사면체 단면, 재료·변위·응력과 지지·하중을 표시한다.

체적의 회전은 별도의 절점 회전 자유도가 아니라 변위구배에서 회복한다.
표면 이력은 면적 가중 운동과 합산 반력이다. 반력 모멘트는 지정한 기준점에
대한 선택 영역의 합력 모멘트다. 단면력은 기준 형상의 지정 평면과 사면체를
교차시킨 물질 단면을 변위로 이동시킨 뒤 응력 traction을 적분한다. 공간에
고정된 평면에서 매 순간 새로 자르는 출력이 아니다. 평면이 요소 면과 정확히
겹치면 법선의 음의 쪽 요소가 소유하므로 내부 면을 두 번 적분하지 않는다.
선택 영역에 음의 쪽 요소가 없는 외곽 평면은 적분 대상이 없다.
이 의미가 달라진 출력은 이전 계약과 버전으로
구별한다. 적분점 응력과 Viewer용 셀 평균 응력은 서로 다른 출력이다.
평균 응력은 구속점의 특이 응력이나 메쉬 수렴을 대신하지 않는다.

## 시간창, 연성 및 상태

각 `sim.run`은 기존 ABI 3 child 실행을 따른다. 동일 checkpoint의 trial을
반복하고 파형 수렴 후에 다음 구간을 채택한다. 운동·하중의 모델 식별자,
실제 시간과 생성된 표본 식별자가 일치해야 한다. 생성된 번호는 그 모델
안에서만 유효하며 형상이나 메쉬 프로파일을 바꾼 상태를 재사용하지 않는다.

연성 하중·제어 포트, 취소와 체크포인트 수명은 유지한다. 부가질량은 구조의
무게가 아니므로 자중에는 포함하지 않는다. 외력 합력 전달은 원본 Geometry
영역을 선택하고 필요하면 부가질량 가속도 항을 되돌려 실제 외력을 복원한다.
구조 관성·내부력을 포함한 동적 절단면 하중을 복원한 것은 아니다.
이 마지막 표본의 합력 전달은 정적·좌굴 예비하중에만 사용한다. 모달·주파수응답·
시간해석에 이 규칙을 선언하면 오류이며, 시간 파형 전달로 암묵적으로 해석하지 않는다.
운동 파형·절점 하중·회전자 제어 입력은 시간해석에서 소비한다. 회전자 없는
제어 입력이나 대응 합력 전달 규칙 없는 원본 입력을 조용히 무시하지 않는다.
체적 물리 절점에 독립 회전 자유도가 있는 것처럼 점 모멘트를 주면 오류다.
연성 생산자는 면 그룹의 내부 부착 기준점을 `regionReferences` 메타데이터로
찾아 힘·모멘트를 전달하거나, Geometry 영역의 합력 전달을 사용한다. 이 번호를
task에 고정해서 쓰거나 다른 메쉬 모델에 재사용하지 않는다.

Box Grid 시간 이력의 scope는 누적(`cumulative`), 마지막 완료 구간
(`latest-window`), 현재 성공 호출 이후 마지막 채택 표본 하나(`final`)를
선택한다. `final`도 후속 호출 예정 여부와 무관하게 길이 1의 time 축을
반환한다. 자동 mesh 변위 시각화는 누적 이력을 별도로 보존한다.
취소·미수렴 trial의 이력은 확정 상태에 누적되지 않는다. 출력 격자의 시간
덧셈 오차와 실제 적분·평형 허용오차는 구별한다.

## 검증

Geometry/mesh 시험은 Boolean 구멍, 양의 체적, 표면 출처, 재료 경계,
품질과 캐시 재현성을 확인한다. 구조 수치 시험은 patch, 가상일, 강체 운동,
접선, 에너지·운동량과 수렴을 확인한다. 공식 Catalog 예제의 실제 child 실행은
CSG·재료 선택·해석 종류·기록·상태 수명을 함께 검사한다. 기존 보·쉘의 숫자와
새 체적 모델의 숫자가 같아야 한다는 것을 동등성 기준으로 사용하지 않는다.

예제 검색·빌드·실행 절차는 [Solver 작성 가이드](../authoring/solver.md)를
따른다. `build`는 Solver를 실행하지 않고, `test`가 실제 로컬 계산을 수행한다.
먼저 현재 Catalog의 선언과 예제를 조회하고 검증할 형상·하중·공간 및 시간
해상도를 명시한다.
