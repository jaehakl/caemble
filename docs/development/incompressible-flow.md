# CSG 비압축성 정상·시간 유동

이 Solver는 하나의 연결된 고정 3차원 CSG 유체 체적에서 비압축성 유동을 푼다.
밀도와 점성은 균일하며 모두 양수다. 정상 Stokes 해석과 시간영역 층류
Navier–Stokes 해석을 명시적으로 선택한다. 정상 덕트·시동 유동, Boolean 채널의
장애물 하중과 CFD/SPH 주기 채널 비교 예제, Material 계수와 정확한 Task 문법은
SQLite Catalog에서 조회한다. 예제에 포함된 Calculation 정의도 같은 Catalog에서
가져오며 별도의 소스 사본을 유지하지 않는다.
Solver의 계산 메시와 관측 Box는 독립적이다. 제거된 Solver 버전의 입력은
거부하며 기존 정상 문제에 시간적분을 암묵적으로 추가하지 않는다.

## 계산과 경계

Canonical Geometry service가 만든 사면체 메시와 표면 provenance를 사용한다.
셀 압력·속도와 면 체적유량을 계산하며, 내부 면의 단일 유량을 이웃 두 셀에
반대 부호로 적용한다. 가중 최소제곱 기울기 복원, 비직교·skewness 보정과
압력–속도 결합은 Solver의 수치 계층에서 소유한다. 기존 직교 격자 Heat와
Current 연산을 유체 계산에 맞추어 변경하지 않는다.
기울기는 면으로 연결된 이웃과 그 다음 이웃까지 사용한다. 이 확장된 stencil은
얇고 비직교성이 큰 사면체에서도 선형장 복원에 필요한 방향 정보를 보강한다.
주기 연결을 지나는 경로에는 누적 병진을 적용하고, 교차 면적비의 곱을 합산해
같은 주기 패치를 더 잘게 나누어도 가중치가 달라지지 않도록 한다.

압력 보정은 restarted GMRES로 결합 선형계를 푼다. 정상 해석은 SIMPLE 전처리를
사용하고, 시간 해석은 관성·점성 비율을 반영하는 Cahouet–Chabard 형태의
역전처리 `mu M_p^-1 + (rho/dt) L_p^-1`를 사용한다. 여기서 `M_p`는 셀 체적
대각행렬, `L_p`는 초기 압력 투영과 같은 이산 Laplacian이다. 초기화 때 만든
factorization을 재사용하며 시간간격이 달라지면 관성 가중치만 바꾼다.
이는 실제 압력–속도·Rhie–Chow 연산을 바꾸지 않는 대수적 전처리다.
[일반화 Stokes 전처리 해설](https://www.math.uh.edu/~molshan/ftp/pub/gstokes.pdf)의
연속 연산자 형태를 셀 적분식에 맞추어 적용하며, 이 메시에서의 효과는 별도
수치 검사로 평가한다.
각 Krylov 보정은 운동량 방정식과 동일한 Rhie–Chow 면 유량을 통해 압력
연산자의 작용을 계산한다. 재시작 길이는 최대 200이며 반복 한도는 재시작
횟수가 아니라 실제 압력 보정 횟수다. Krylov 최소제곱은 증분 Givens QR로
갱신한다. 추정 잔차가 목표에 도달하거나 재시작·Arnoldi 종료·반복 한도에
이르면 후보 압력·속도·면 유량의 실제 잔차를 다시 계산한다. 추정 잔차는
검사 시점만 정하며, 결과 반환에는 실제 운동량·질량·압력 잔차가 모두 수렴해야
한다. 기본 운동량 LU 해에는 원래 방정식의 잔차로 한 번의 보정을 적용해
작은 시간간격에서의 반올림 오차를 줄인다.

시간 해석은 Arnoldi 관계에서 얻은 harmonic Ritz 압력 방향을 최대 8개
보관한다. 매 Krylov 재시작에서 현재 압력 연산자로 이 방향들을 다시 평가하고
pivoted QR로 독립적인 부분공간을 구성한다. 이 부분의 보정과 나머지 성분의
Cahouet–Chabard 전처리를 함께 사용한다. 각 재시작을 준비하는 추가 연산은
최대 8회이며 전처리 작업으로 구분하고, 실제 압력 보정의 반복 한도와 최종
수렴 기준은 유지한다. 추가 연산마다 취소를 확인한다.
[Harmonic Ritz 재시작의 근거](https://doi.org/10.1137/S1064827599364659)를
따르되, 보관한 방향은 한 후보 timestep의 재시작과 Picard 반복 사이에서만
사용한다. 재시도도 새 후보이므로 빈 부분공간에서 시작하며 승인된 다음
timestep이나 checkpoint로 전달하지 않는다.

정상 Stokes는 이류와 물리적 시간적분을 포함하지 않는다. 시간 해석은 backward
Euler의 관성항과 보존형 upwind 이류를 추가하고, 이류에 사용한 면 유량이
압력–속도 해와 일치할 때까지 비선형 반복한다. 두 해석 모두 최종 셀별
질량수지와 운동량 잔차를 확인한다. 시간 해석의 시간·이류 정확도는 1차이며,
난류 모델이나 고차 이류법의 결과로 해석하지 않는다. 1차 upwind의 수치 확산은
이동하는 파형과 속도 분포를 감쇠시킬 수 있다. 시간 간격만 줄여서는 이 공간
오차가 사라지지 않으므로 공간 정련 결과를 함께 확인한다.

미지정 표면은 정지 no-slip 벽이다. 지정 속도는 world 벡터이며, 표면 법선이
유입·유출 부호를 결정한다. 압력 개방면은 gauge pressure와 속도의 법선 방향
기울기 0을 적용하고 양방향 유량을 허용한다. 유량 부호로 경계조건을 전환하거나
유입을 잘라내지 않는다. 명시한 선택이 비어 있거나 다른 조건과 중복되면 오류다.
분리된 유체 영역, 순유량이 맞지 않는 폐쇄 경계와 속도 기준이 없는 전면 개방
조건도 오류로 보고한다.

일정 중력은 체적 중심을 기준으로 감소압력에서 분리한다. 주기 방향 성분은
일정 체적 가속도로 운동량식에 남기고, 주기 이동과 양립하는 직교 성분만
정수압으로 분리한다. 경계 압력과 출력은 이 정수압을 복원한 Pa gauge pressure다.
압력 개방면이 없으면 유체 체적 평균 압력을 0으로 두며, 개방면이 있으면
지정된 압력이 기준이다. 압력 종류·기준·기준점, 정수압 가속도와 구동 가속도,
좌표계는 선언된 결과 metadata로 Box Record와 native Field에 저장한다.
실행 trace가 없어도 저장된 결과 자체에서 기준을 확인할 수 있다. 과거에
저장한 결과는 당시 schema로 읽고 누락된 압력 기준을 임의로 추정하지 않는다.
결과 승인은 압력 선형계뿐 아니라
최종 운동량 잔차와 보정된 면 유량의 셀별 질량수지를 함께 확인한다.

결과 schema는 metadata의 이름별 dtype·shape·물리량·단위와 선택적인 문자열
허용값을 선언하고, Candidate에서 해석한 실제 값은 tensor metadata에 저장한다.
실제 값을 static Box profile에 섞지 않는다. Native Field도 선언한 metadata만
저장 projection에 남기며 실제 시각은 sampleAxes에서 제공한다. Calculation은
불변 metadata와 그 schema를 함께 받는다. Prediction은 새 Candidate의 이
metadata를 복원할 수 없으므로 해당 출력의 추론을 명시적으로 거부한다.
metadata가 없는 기존 출력의 Prediction 동작은 유지한다.

## 주기 경계와 표면 관측

주기 경계는 순서 있는 두 표면 선택과 첫 표면을 둘째 표면으로 옮기는 world
병진 벡터로 정의한다. 두 경계는 평행한 평면이고 외향 법선이 반대이며,
이동한 영역이 완전히 일치해야 한다. 삼각분할이 달라도 실제 삼각형 교차
영역에서 공통 연결과 한 번 계산한 유량을 구성한다. 각 면적이 빠짐없이
덮이는지 검사하며 누락·중복·회전·슬라이딩·부분 겹침을 보간 fallback으로
대체하지 않는다. 여러 주기 방향을 함께 지정할 수 있다.
같은 방향의 서로 겹치지 않는 표면 쌍도 허용하며, 중력 분해에는 병진 벡터들이
만드는 공간의 독립 성분만 사용한다.

공통 주기 연결은 압력 보정, 속도·점성·이류 연산, Courant 평가와 이전 면 유량의
관성항에 동일하게 적용한다. 이웃 셀 중심도 주기 이동한 위치에서 사용한다.
주기 방향 가속도로 유동을 구동하며 추가적인 압력 jump 입력은 제공하지 않는다.

표면 관측은 Geometry의 이름 있는 표면 그룹을 초기화 선언에서 선택하고,
출력이 그 관측 이름을 참조한다. 수치 출력의 target은 기존 관측 Box로 유지한다.
관측 선언이 참조하는 실제 유체 경계가 비어 있거나 다른 유체의 표면이면
오류다. 관측 선택은 경계조건을 추가하거나 물리 해를 바꾸지 않는다.

경계 체적유량은 압력 보정까지 반영한 면 유량으로 계산하며 셀 속도로 다시
만들지 않는다. 질량유량은 그 값에 일정 밀도를 곱한다. 부호는 유체 밖을 향한
법선 기준으로 유출이 양수이고 유입이 음수다. 표면 압력은 실제 선택 면적의
평균이다. 모든 aggregate는 관측 Box와 삼각형의 실제 교차 영역을 적분한다.
면 중심이 Box 밖에 있어도 교차한 부분은 포함하며, 빈 교차 결과는 0이다.

## 표면 하중과 독립적인 전달 값

정지 벽과 장애물의 유체가 고체에 가하는 traction은 유체 외향 법선
`n_f`에 대해 `t = -sigma n_f`로 정의한다. Cauchy 응력은
`sigma = -p_load I + mu (grad(u) + grad(u)^T)`이며
`p_load`는 gauge pressure에 명시적인 pressure offset을 더한 값이다.
기본 offset은 0이다. 개방면과 주기면을 고체 하중 대상으로 선택하면 오류다.
표면에서 재구성한 물리 압력과 속도 기울기를 사용하고 정수압도 복원한다.

힘은 traction의 면적 적분, 모멘트는 명시한 world 기준점에 대한 적분이다.
전체·압력·점성 기여를 구분해 요청할 수 있다. 압력 offset, 기여 구분,
유체 외향 법선, 유체가 고체에 가하는 작용, 표면 선택과 모멘트 기준점은
해당 결과의 선언된 metadata로 남는다. 주어진 압력차를 고정한 형상 비교에서는
유량·힘·모멘트를 비교한다. 입출구의 정압 차이를 별도의 검증 없이 비가역
압력 손실이나 최적화 결과로 해석하지 않는다.

Native traction export는 실제 창 끝 시각의 독립적인 삼각형 표면 메시와
셀 vector Field다. World 좌표·연결성·표면 provenance·basis·압력 기준을
함께 전달하므로 생산자 state 해제 후에도 다른 child가 원래 Geometry를
조회하지 않고 힘과 모멘트를 복원할 수 있다. 자동 traction 시각화는 관측이나
export 요청과 무관하게 모든 실제 no-slip 벽의 전체 하중을 offset 0으로
표시한다. 벽이 없는 완전 주기 문제에서는 빈 표면 snapshot을 반환한다.
분포의 전체 시간 이력, 실제 구조 Solver 입력이나 양방향 유체–구조 연성은
이 범위에 포함하지 않는다.

복원한 traction은 각 원래 경계 삼각형에서 일정한 cell Field로 정의한다.
Aggregate와 native export는 이 값을 공유한다. Box에 잘린 다각형의 정확한
면적과 1차 면적모멘트를 사용하므로 독립 소비자의 힘·모멘트 적분과 일치한다.
연속 응력과 이 삼각형별 표현의 차이는 공간 정련으로 평가하며, 운동량 잔차나
힘의 재조정으로 이 오차를 대신하지 않는다.

## 시간창과 승인 상태

시간 해석의 첫 호출은 속도·면 유량 0에서 시작한다. 첫 투영은 경계의 지정
유량을 지키며 속도·면 유량을 divergence-free 상태로 만들고, 별도의 가속도
투영이 초기 물리 압력을 정한다. 초기 해로 정상 Stokes 해를 대신 사용하지
않는다. 이후 각 호출은 지정한 시간창을 진행하며 마지막 창은 전체
해석 종료 시간에서 멈춘다. 시간창과 전체 종료 시각은 실제 적분 경계이고,
관측 표본 시각은 적분 경계를 추가하지 않는다.

각 trial은 마지막 승인 압력·속도·면 유량에서 시작한다. Courant 제한이나
비선형 수렴을 통과하지 못하면 동일한 승인 상태에서 timestep을 절반으로
줄여 최대 12회 재시도한다. 성공 뒤에는 다음 timestep을 최대 1.25배 늘리되
설정한 상한을 넘지 않는다. 다음 trial을 제안할 때에는 승인 유량으로 예상한
Courant 수가 설정한 한도의 0.9배가 되도록 안전 여유를 둔다. 실제 trial의
최종 유량으로 Courant 제한을 다시 검사한다. 승인되지 않은 trial의
상태·표본·시간은 다음 호출로 넘어가지 않는다. 호환되지 않는 상태,
재료나 경계 입력의 오류를
timestep 재시도로 숨기지 않는다.

시간 state는 현재 물리량과 시간, 다음 timestep, 누적 관측 이력 및 입력
동일성 정보를 보존한다. 표면 관측을 위해 승인한 경계 유량도 이력에 보관한다.
새 관측 선택이나 Box가 추가되어도 보관한 물리 상태에서 다시 관찰할 수 있다.
재생성 가능한 메시 연산자와 factorization은 child workspace에 두고,
Krylov 벡터는 각 후보 timestep에서 새로 만든다. 따라서 같은 timestep
열을 진행하면 한 창 실행과 checkpoint에서 나눈 실행의 물리 배열이 일치한다.
Geometry·Material·물리 경계·수치 설정이 달라진
state continuation은 거부한다. `dt`, `duration`, `windowSize`도 continuation
동안 고정한다. 관측 Box·해상도·scope는 물리 계산을 바꾸지 않으며 서로 다른
기록 설정으로 같은 승인 해를 관찰할 수 있다. `outputInterval`을 변경하면
변경 이후의 표본 일정에만 적용하며 이미 보관한 관측 이력을 다시 표본화하지
않는다.

기존 Runtime의 run-scoped state handle을 보관하면 checkpoint로 사용할 수
있다. `sim.run(state=...)`으로 그 revision에서 다시 시작하고 `sim.release`
의 `keep`으로 보관할 handle을 보호한다. 이는 한 Measurement 실행 안의
immutable revision이며 프로세스를 종료한 뒤 읽는 영속 checkpoint 파일은
아니다. Solver는 자동으로 원격 작업을 제출하거나 실패한 작업을 재실행하지
않는다.

## 기록과 자원 수명

관측 Box local 좌표에서 사면체와 각 관측 셀의 실제 교차 체적을 계산한다.
압력·속도는 교차한 유체 체적 평균이고, 질량밀도는 교차 영역의 질량을 관측
셀 전체 체적으로 나눈 값이다. 빈 셀은 0이며 음의 압력도 유지한다. 같은 Box에
기록한 질량밀도가 양수인지 검사하면 유효한 압력 0과 빈 셀을 구분할 수 있다.
Box 안에 계산 셀 중심이 없어도 교차 체적이 있으면 관측에 포함한다.

기록은 기존 일곱 축 Box Grid를 따른다. 정상 해석의 time 표본은 0이며,
시간 해석의 time 축은 실제 초 단위 표본이다. frequency 축은 두 해석 모두
단일 0 표본이다. 누적 출력은 현재 호출까지의 관측 이력과 현재 창 끝 값을
포함하고, final 출력은 성공한 현재 창의 실제 끝 값 하나다. 창 끝의 임시
관측값을 다음 창의 정규 표본 이력에 중복 저장하지 않는다.

관측 간격에 맞춘 값은 승인된 시간 상태를 보간하여 만든다. 관측 표본을
만들기 위해 물리 timestep을 쪼개거나 수치해를 다시 풀지 않는다. Native
사면체의 셀 압력·속도는 실제 창 끝 time 좌표를 가진 마지막 snapshot으로
자동 mesh-field visualization에 별도 저장한다. 관측 해상도와 회전은
계산 메시·물리적 해·수렴 기준을 바꾸지 않는다.

정상 호출은 빈 StatePatch를 반환하고 시간 호출은 승인한 창의 state만
commit한다. 기록·ACK·해제, 실패·취소 시 rollback과 child 정리는 기존
Runtime 경로를 사용한다. 시간에 따라 달라지는 공개 경계조건, 임의의 초기장 입력과
프로세스 종료 후 재개하는 영속 checkpoint도 제공하지 않는다.

## CFD와 SPH 결과 비교

주기 채널 비교 예제는 두 Task를 하나의 Measurement에서 실행하고 같은 Box와
관측 시각의 Record를 Calculation에 전달한다. Native export와 시각화는
Calculation 입력으로 사용하지 않는다. 두 계산을 먼저 각자의 공간 평균에
맞는 시동 Poiseuille 기준해와 비교한 다음 서로 비교한다. CFD의 체적 평균과
SPH의 입자 위치 귀속·질량 가중 속도는 서로 다른 관측 연산이다.

공통 유량 지표는 채널 길이로 나눈 Box 내 운동량의 적분을 기준 밀도로 환산한
값이다. CFD는 전체 관측 셀 체적당 질량밀도와 유체 평균 속도의 곱을,
SPH는 기존 운동량밀도 Record를 사용한다. 부분 점유와 빈 셀을 반영하지만
WCSPH의 밀도 변화도 포함하므로 정확한 SPH 경계 체적유량이라고 표시하지
않는다. CFD의 보정된 경계 유량은 별도 곡선으로 함께 기록한다.

압력 비교는 각 시간의 점유 영역에서 질량 가중 공간 평균을 제거한 뒤 수행한다.
기준해의 압력 변동이 0인 경우 상대오차 대신 Pa 단위 RMS를 사용한다.
총질량은 전체 Box 셀 체적당 질량밀도의 적분으로 별도로 확인한다.

## 검증

관련 수치 검사는 정수압, 압력차 구동 덕트와 공간 수렴, 지정 속도와 질량수지,
압력차 반전, 불규칙 메시, Boolean 경계와 연결성을 확인한다. 시간 검사는
시동 유동·시간 수렴·이류·Courant 제한, 재시도와 승인 상태 보존, 창 분할과
checkpoint 재생을 확인한다. 관측 검사는
회전 Box, 길이 단위 변환, 부분 점유와 총질량 보존을 확인한다. 표면 검사는
유량 상쇄, 교차 면적 적분, 압력·점성 하중 분리, 정수압 부력과 모멘트,
주기 교차 연결의 전체 면적 보존 및 공간·시간 수렴을 확인한다. 공개 CLI로
Catalog 예제를 빌드하고 실제 ABI 3 child와 기록 저장·재조회를 검증한다.
부분 개발은 `affected --list`로 선택 이유를 확인하고 관련 검사와 CPU `quick`을
실행한다. CAE `full` 실행 여부는 별도로 요청된 검증 범위를 따른다.
