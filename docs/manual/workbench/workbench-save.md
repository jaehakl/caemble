# Experiment 저장과 버전 관리

Experiment를 저장하면 형상과 변수, 재료, Solver 작업을 다시 열 수 있습니다. 실행 결과가 이미 연결된 버전은 그대로 보존하고 새 버전으로 이어서 작업합니다. 이 문서에서는 저장 방법과 대표이미지, 처음 보이는 결과를 설정하는 방법을 안내합니다.

## Save와 Save As

처음 만든 작업은 **Save**를 눌러 이름과 저장 위치를 정하세요. 기존 작업을 복사하거나 새 버전으로 남기고 싶다면 **Save As**를 사용합니다.

| 현재 상태 | **Save**를 눌렀을 때 |
| --- | --- |
| 아직 저장하지 않은 Draft | Save As 창을 엽니다. |
| 저장된 Experiment에 Measurement가 없음 | 서버에서 최신 사용 상태를 확인한 뒤 덮어씁니다. |
| Measurement가 하나 이상 있음 | 해당 Experiment를 대상으로 Save As 창을 엽니다. |
| 읽기 전용 Experiment | Save는 비활성화됩니다. **Save As**를 직접 눌러 내 작업으로 복사하세요. |

### 새 Experiment로 저장하기

**Save As**의 기본 동작은 새 Experiment를 만드는 것입니다. 기존 작업을 복사할 때는 key 뒤에 `-copy`를 붙인 값을 제안합니다. 같은 저장 위치에 그 key가 이미 있다면 다른 key를 입력하세요. 기존 작업의 새 버전으로 저장하려는 경우에는 왼쪽에서 해당 카드를 선택합니다.

namespace와 Repository는 저장 위치를, key는 그 안에서 같은 작업의 버전들을 묶는 이름을 나타냅니다. 이름과 설명을 확인한 뒤 저장하세요.

### 기존 작업의 새 버전 만들기

왼쪽에서 쓰기 권한이 있는 카드를 선택하면 저장 대상의 namespace·Repository·key가 고정됩니다. 현재 편집 중인 소스, 이름, 설명과 Viewer 화면은 그대로 유지됩니다.

대상 작업의 최신 버전에서 **Patch**(기본값), **Minor**, **Major** 중 하나를 올립니다. 기존 대상에 저장하면 대상의 Calculation 정의를 이어받습니다. 새 Experiment를 만들 때는 현재 작업에 적용되는 Calculation 복사 정책을 따릅니다.

저장이 끝나도 창은 열린 채로 남고 저장된 카드가 선택됩니다. Workbench의 선택과 URL도 갱신됩니다. 확인 후 **닫기**를 누르세요. 다른 곳에서 같은 작업이 변경되어 저장이 거부되면 갱신된 목록과 사용 상태를 확인한 뒤 다시 저장합니다.

## 대표이미지 고르기

Save As를 열면 현재 Viewer의 형상·결과·범례를 한 장의 이미지로 캡처합니다. 툴바와 메뉴는 포함하지 않습니다. 미리보기의 4:3 사각형으로 카드에 표시할 영역을 고르세요.

- 사각형을 드래그하면 위치가 바뀌고, 오른쪽 아래 핸들을 드래그하면 크기가 바뀝니다. 처음에는 중앙에서 가장 큰 영역이 선택됩니다.
- 키보드로는 사각형에 포커스를 두고 방향키로 이동합니다. 핸들에 포커스를 두면 오른쪽·아래 방향키로 확대하고 왼쪽·위 방향키로 축소합니다. Shift를 함께 누르면 더 크게 조절합니다.
- 창을 열지 않고 바로 Save하는 경우에는 중앙의 가장 큰 영역을 사용합니다.

대표이미지는 최대 640×480 크기의 WebP로 저장하며 파일 크기는 최대 512 KiB입니다. 화면이 비었거나 캡처에 실패하면 이유를 표시합니다. 기존 작업을 덮어쓸 때는 이전 이미지를 유지하고, 새로 저장할 때는 기본 이미지를 사용합니다.

## 초기 화면과 대표이미지 수정

작업을 열었을 때 보여 줄 결과와 카메라를 지정하려면 Viewer의 **초기 화면·대표이미지 → 현재 화면을 초기 화면으로 저장**을 누릅니다. 현재 Measurement, 선택한 데이터, 표시 옵션과 카메라를 함께 저장합니다.

저장된 소스의 기록 완료 Measurement를 보고 있을 때 사용할 수 있습니다. 임시 실행이나 Prediction 결과를 표시 중이거나 소스를 편집 중일 때는 초기 화면을 저장할 수 없습니다.

설정은 현재 Experiment 버전에 속합니다. 새 버전을 만들지 않고 나중에 바꿀 수 있으며, 일반 Experiment는 소유자와 관리자, Demo는 관리자만 변경할 수 있습니다. 새 버전에 이 설정을 자동으로 복사하지는 않습니다.

Showcase와 Demo를 포함해 해당 버전의 Viewer를 처음 열 때 저장된 설정을 적용합니다. 이후 데이터가 갱신되거나 화면을 확대해도 사용자가 바꾼 표시와 카메라를 되돌리지 않습니다. 다른 결과에 일부 데이터나 옵션이 없다면 해당 부분만 기본값을 사용합니다.

**초기 화면 설정 해제**를 누르면 고정한 Measurement와 Viewer 기본 설정을 함께 해제합니다. 다음에 열 때부터 가장 최근 결과를 사용합니다.

**대표이미지 변경**은 현재 Viewer를 캡처하고 4:3으로 잘라 저장합니다. 초기 화면 설정과 별도로 바꿀 수 있으며, 같은 버전의 Showcase 카드에도 반영됩니다. 캡처나 저장에 실패하면 기존 이미지를 유지합니다.

## Preflight 결과 함께 저장하기

Preflight는 저장 전에 시험 실행해 확인한 임시 결과입니다. 완료된 유효한 결과가 있으면 **Preflight 결과 함께 저장**이 기본으로 켜집니다. 리본과 Save As에서 같은 옵션을 사용합니다.

함께 저장하려면 현재 소스와 결과 규격이 실행 당시와 일치해야 합니다. 본인 소유의 성공 결과만 실행 후 24시간 안에 저장할 수 있습니다. 만료되었거나 내용이 달라졌다면 다시 실행하거나 포함 옵션을 끄세요.

이 옵션으로 저장하면 Solver를 다시 실행하지 않고 기록 완료 Measurement를 만듭니다. 실행 당시 변수·재료·형상·RecordedData·시각화·실행 추적과 저장 객체를 독립적으로 보존합니다. 임시 결과가 만료되어 정리되거나 다른 저장본이 삭제되어도 함께 저장한 결과에는 영향을 주지 않습니다.

서버 저장에 성공하면 새 Measurement가 선택되고, 화면의 임시 Preflight 결과도 영구 저장된 결과로 전환됩니다.
