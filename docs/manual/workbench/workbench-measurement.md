# Measurement에서 조건 만들고 실행하기

같은 Experiment도 변수값에 따라 형상과 결과가 달라집니다. **Measurement** 탭에서는 계산할 조건을 만들고, 필요한 조건을 선택해 실행한 뒤 예측과 실제 결과를 비교합니다.

처음 한 번 실행하는 과정은 [빠른 시작](workbench-quickstart.md)에 있습니다. 여기서는 변수 편집과 여러 후보를 다루는 방법을 자세히 살펴봅니다.

## Measurement 탭

먼저 편집 가능한 내 Experiment를 저장하고 소스가 준비된 상태인지 확인하세요. 실행하려면 로그인과 연결된 CAE Launcher도 필요합니다.

화면 왼쪽 위는 변수 조건을 점으로 보여 주는 **Vars PCA**, 아래는 **Vars 편집기**입니다. 오른쪽에는 구조와 Forward 예측을 보여 주는 미리보기 Viewer와 실제 결과 Viewer가 나란히 있습니다. 좌우 기본 비율과 두 Viewer의 기본 비율은 모두 50:50이며 구분선을 드래그하거나 방향키로 조절할 수 있습니다.

오른쪽 맨 위에는 공통 가로 툴바가, 비교 영역 왼쪽에는 데이터별 세로 툴바가 있습니다. 두 Viewer의 표시 설정은 함께 바꾸고 카메라는 각각 조작합니다.

| 상태 | 의미 | 다음 행동 |
| --- | --- | --- |
| 후보(Candidate) | 현재 작업에서 만든 임시 변수 조건입니다. | 값을 확인한 뒤 저장하거나 실행합니다. |
| Prepared Measurement | 변수와 재료가 저장되었고 결과는 아직 없습니다. | 저장한 조건 그대로 실행합니다. |
| Recorded Measurement | 실행 결과가 저장되어 있습니다. | 결과를 확인하거나 새 후보의 비교 기준으로 사용합니다. |

### Vars 편집

Vars 목록에서 바꿀 항목을 선택하면 오른쪽에 편집기가 열립니다. 각 버튼은 변수 이름과 스칼라값, 또는 배열의 크기(shape)와 평균을 보여 줍니다. 스칼라는 숫자 하나, 텐서는 여러 숫자를 배열로 묶은 값입니다.

| 변수 형태 | 편집 방법 |
| --- | --- |
| 스칼라 | 숫자를 입력하거나 수직 슬라이더를 움직입니다. 위쪽이 최댓값, 아래쪽이 최솟값입니다. |
| 1차원 텐서 | 가로로 나열된 각 원소의 숫자 입력칸과 수직 슬라이더를 사용합니다. |
| 2차원 텐서 | 배열 크기에 맞는 격자에서 숫자를 편집합니다. |
| 3차원 이상 | 앞쪽 축의 인덱스를 고른 뒤 마지막 두 축의 단면을 편집합니다. |

Enter를 누르거나 입력칸 밖으로 이동하면 값이 확정됩니다. Escape는 편집을 되돌립니다. 확정하지 않았거나 잘못된 입력이 있으면 저장과 Run을 사용할 수 없습니다. 변수에 정해진 범위를 벗어난 값은 반영하지 않습니다.

원소 인덱스를 클릭해 선택하고, Ctrl/Cmd를 누른 채 클릭하면 선택을 추가하며, Shift로 범위를 선택합니다. 격자에서는 인덱스를 드래그하거나 Shift+방향키로 사각 영역을 선택할 수도 있습니다. **전체 tensor** 또는 **선택** 영역에 채우기·더하기·곱하기를 적용할 수 있습니다. 결과 중 하나라도 범위를 벗어나면 해당 일괄 작업 전체를 반영하지 않습니다.

**Shuffle · 전체**는 선택한 텐서의 모든 원소를 min/max 범위에서 무작위로 다시 만듭니다. 보이지 않는 고차원 단면도 포함하며 다른 변수는 바뀌지 않습니다. 값 편집과 Shuffle만으로 Solver가 실행되지는 않습니다.

### PCA와 후보 생성

PCA는 여러 변수로 이루어진 조건들을 평면 위의 점으로 요약해 보여 주는 방법입니다. 점을 클릭하면 해당 조건을 선택할 수 있습니다. 처음에는 생성 방식과 개수로 후보를 만든 뒤 점을 선택해 살펴보세요.

1. **Random** 또는 **빈 구간 LHS**를 고릅니다.
2. 만들 후보 수 **N**을 입력합니다. 기본값은 10이며, 처음에는 1로 시작해도 좋습니다.
3. **후보 생성**을 누르고 관심 있는 후보의 변수와 형상을 확인합니다.
4. 현재 편집값을 별도 후보로 남기려면 **후보 추가**를 누릅니다.

**Random**은 범위 안에서 균등한 확률로 값을 뽑습니다. **빈 구간 LHS**는 각 성분에서 기존 Measurement와 후보가 차지하지 않은 구간을 사용합니다. 빈 구간이 N개보다 적으면 구간을 더 나누어 고르게 생성합니다.

PCA는 Measurement와 후보의 Vars를 각 변수 범위로 정규화한 뒤 분석합니다. 범위의 경계에 가상점을 추가하지는 않습니다. 빈 공간을 클릭하면 PCA 거리상 가까운 최대 7개 이웃의 변수값을 거리의 역수로 가중 평균하고, PC1·PC2를 클릭한 위치로 옮겨 후보를 만듭니다. 허용 범위를 벗어나면 보정된 위치를 표시합니다.

편집 중에는 PCA 축과 이웃을 고정하므로 같은 위치를 반복 클릭해도 변수값이 누적해서 바뀌지 않습니다. **PCA 갱신**을 누르면 편집값을 분석에 반영합니다. 점들 사이에 차이가 없어 분산을 계산할 수 없다면 먼저 후보를 생성하세요.

## 저장하고 실행하기

후보는 탭을 이동해도 유지되지만 새로고침 후에도 남기려면 **Prepared 저장**을 사용해야 합니다. 이 버튼은 현재 변수와 재료를 저장하며 Solver를 실행하지 않습니다.

- **선택 Run**: 선택한 후보나 Prepared Measurement를 실행합니다. 선택 집합이 없으면 현재 조건을 사용합니다.
- **전체 후보 Run**: 후보 목록을 차례로 실행합니다. 현재 편집 중인 조건도 대상에 포함될 수 있으므로 실행 전 선택과 후보를 확인하세요.
- 이미 **Recorded**인 Measurement는 다시 실행하지 않습니다. 다른 조건으로 계산하려면 새 후보를 만드세요.

Run은 검토한 Vars를 그대로 제출합니다. 기존 Prepared Measurement는 새 ID를 만들지 않고 해당 ID로 실행합니다. 각 후보의 실패·취소 상태는 후보 목록에서 확인할 수 있습니다.

입력 준비와 업로드가 끝나 서버 접수가 완료된 작업은 브라우저를 닫아도 계산을 계속합니다. 아직 준비·업로드 중인 작업과 다음 후보의 제출, 브라우저에서 수행하는 Calculation 후처리를 계속하려면 브라우저를 열어 두세요.

### 작업 상태와 오류 확인

**Console**에서 작업별 진행률과 완료·실패 알림을 확인합니다. **Setting → CAE Jobs**에는 최근 배치 **50개**와 진행 중이거나 완료 알림을 아직 확인하지 않은 배치가 먼저 표시됩니다. 이전 이력은 **더 보기**로 불러옵니다. 배치를 펼치면 개별 작업의 상태와 오류를 확인할 수 있으며, 연결이 복구되면 마지막으로 받은 이벤트부터 변경 사항을 이어받습니다.

실패한 작업은 자동으로 다시 실행하지 않습니다. Launcher나 서버 연결이 끊겨 실패한 경우도 마찬가지입니다. 원인을 해결한 뒤 CAE Jobs에서 명시적으로 재시도하세요. **Batch 취소**는 아직 끝나지 않은 작업을 취소합니다.

실행 입력과 큰 결과 본문은 객체 저장소(S3)를 통해 브라우저와 CAE worker 사이에 전달됩니다. 서버는 권한, 데이터 참조와 작업 상태를 관리합니다. worker의 결과 업로드와 RecordedData 참조 저장이 모두 끝나면 Recorded 상태가 되며, 선택 중인 Measurement는 완료 이벤트를 받으면 결과를 다시 불러옵니다.

### Forward와 실제 결과 비교

Forward는 기존 실제 결과에서 학습해 현재 조건의 결과를 예상합니다. **Forward 모델 생성**이나 **모델 업데이트**로 직접 학습할 수 있습니다. 모델이 있으면 Vars를 바꿀 때 예측이 자동으로 갱신됩니다.

**선택 Run**과 **전체 후보 Run**에서는 기존 실제 데이터로 자동 학습합니다. 각 후보의 형상과 예측이 준비되면 미리보기를 전환하고 실제 계산을 시작합니다. 실제 결과는 저장과 다운로드가 끝나는 즉시 표시하며 후속 Calculation 완료를 기다리지 않습니다.

새 결과가 추가되면 Forward 재학습과 다음 후보의 형상 준비를 함께 진행합니다. 준비 중에는 이전 화면을 유지하고, 다음 형상과 예측이 준비되면 미리보기를 먼저 바꿉니다. 실제 결과 Viewer는 해당 계산이 끝났을 때 바뀝니다. 각 Viewer의 후보·Measurement 표시로 어느 조건을 보고 있는지 확인하세요. 비교용 예측은 그 후보를 실행하기 전의 값으로 유지됩니다.

학습 데이터가 없거나 학습·예측이 실패하면 형상과 그 이유를 표시하고 실제 실행은 계속합니다. 새 결과가 생기면 다시 학습합니다. 취소하면 마지막 화면을 유지합니다. 현재 배치 밖에서 데이터가 추가되면 수동 업데이트가 필요하다고 안내합니다.

모델은 탭을 이동해도 유지됩니다. 새로고침하거나 Experiment·소스·변수 규격·사용자가 바뀌거나 브라우저의 학습 Worker가 사라지면 다시 만들어야 합니다. Forward는 숫자형 Box Grid RecordedData를 지원합니다. 다른 결과 형식은 실제 결과를 볼 수 있지만 예측을 지원하지 않는 이유가 표시됩니다. CalculationData 편집과 파생 결과 분석은 [Calculation](workbench-calculation.md)과 [Prediction](workbench-prediction.md)에서 이어서 진행하세요.

## 비교 화면 조절하기

Recorded Measurement를 선택하면 실제 결과 Viewer의 비교 기준이 됩니다. 이후 Vars를 수정해도 그 결과와 실행 당시 형상·재료는 그대로 유지되고, 현재 조건과 다르다는 표시가 나타납니다.

공통 툴바의 Output 패널에서 차트 종류·축·집계·채널·성분·값 범위를 함께 조절합니다. 재생 제어는 별도 버튼에서 결과 이름별 대상을 선택하며 한 번에 하나만 재생합니다. 카메라는 각각 움직일 수 있습니다. 자동 색상 범위는 각 Viewer의 데이터에서 따로 계산하고, 직접 고정한 범위는 양쪽에 똑같이 적용합니다.

Vars나 실제 결과, 모델을 바꿔도 표시 설정과 카메라는 초기화되지 않습니다. 로딩·오류·데이터 누락 중에도 설정과 마지막 재생 위치를 보존합니다. 재생할 데이터가 없어지면 멈추며, 데이터가 돌아오면 같은 위치에서 다시 재생할 수 있습니다. 다른 데이터 항목을 보고 돌아오거나 탭을 이동해도 항목별 설정은 유지됩니다.

새 데이터의 배열 크기에 선택한 성분·단면·프레임을 적용할 수 없으면 값을 임의로 바꾸지 않고 해당 Viewer에 이유를 표시합니다. 공통 툴바에서 유효한 값을 다시 선택하세요. 새 작업공간이나 Experiment를 열거나 페이지를 새로고침하면 새 세션의 기본값을 사용합니다.

각 Viewer는 처음 형상이나 결과가 준비되어 화면에 나타날 때 전체가 보이도록 카메라를 맞춥니다. 이후 데이터가 갱신되어도 카메라를 유지합니다. **전체 맞춤**을 누르면 현재 콘텐츠의 중심과 크기에 다시 맞출 수 있습니다.
