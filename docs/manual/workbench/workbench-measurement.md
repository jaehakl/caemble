# Measurement에서 조건 만들고 실행하기

**시뮬레이션** 탭에서 Vars를 바꾸고 계산한 뒤, 저장된 Measurement를 선택해 결과를 확인합니다. 첫 실행은 [빠른 시작](workbench-quickstart.md)을 참고하세요.

## 시뮬레이션 탭

왼쪽의 **Vars**와 **Measurements**로 조건 편집과 실행 기록 조회를 전환합니다. Viewer에서 형상과 결과를 확인하고 소스 편집기에서 Experiment를 수정합니다.

### Vars 편집

Vars는 스칼라와 텐서 값을 지원합니다. 소스에 선언된 범위 안에서 값을 조절하세요. 막대를 누른 채 위아래로 이동하면 여러 값을 조절할 수 있습니다. 변수 변경은 현재 Candidate와 형상을 갱신하며 Solver를 실행하지 않습니다.

변수를 변경하면 기존 Measurement 선택을 해제합니다. 실행 중이거나 임시 결과를 보는 동안에는 Vars 편집이 잠깁니다. 임시 결과를 닫으면 다시 편집할 수 있습니다.

## 저장하고 실행하기

- **실행**: 현재 준비된 조건으로 계산하고 임시 결과를 표시합니다. 로그인이 필요합니다.
- **재생성 및 실행**: 조건을 재생성한 뒤 계산합니다.
- **임시 결과 닫기**: 임시 결과를 닫고 현재 작업 화면으로 돌아갑니다.

임시 실행만으로 저장된 Measurement가 만들어지지는 않습니다. Experiment 저장 시의 결과 보존은 저장 흐름을 따릅니다. 저장된 여러 조건을 실행하려면 일괄생성을 사용하세요.

### 일괄생성

로그인하고 편집 가능한 Experiment를 저장한 뒤, 소스와 변수가 준비되면 **일괄생성**을 사용할 수 있습니다.

1. **일괄생성**을 엽니다.
2. **Random** 또는 **빈 구간 LHS**를 선택합니다.
3. 생성 개수를 지정합니다. 기본값은 10입니다.
4. **실행**을 눌러 조건들을 하나의 Batch로 제출합니다.

Random은 허용 범위에서 값을 뽑습니다. 빈 구간 LHS는 기존 Measurement와 현재 후보가 차지하지 않은 구간을 사용하며, 필요하면 구간을 더 나눕니다.

서버에 접수되기 전에는 대화상자를 닫아 준비를 취소할 수 있습니다. 접수 완료는 계산 완료를 뜻하지 않습니다. 접수된 Batch는 대화상자를 닫아도 계속 실행됩니다.

### 작업 상태와 오류 확인

하단 **Console**에서 진행 상황과 오류를 확인합니다. **Setting → CAE Jobs**에서 Batch와 개별 작업 상태를 확인하고 취소하거나 실패한 작업을 재시도할 수 있습니다.

## 저장된 결과 확인하기

**Measurements** 목록에서 현재 Experiment의 기록을 선택하면 해당 조건과 결과를 불러옵니다. 결과 불러오기가 성공한 뒤 임시 결과가 닫히며, 불러오기에 실패하면 기존 화면을 유지합니다.

파생 결과 계산은 **후처리** 탭에서, 예측과 실제 결과 비교는 **예측** 탭에서 진행합니다. 자세한 내용은 [Calculation](workbench-calculation.md), [Prediction](workbench-prediction.md), [Viewer 사용법](workbench-viewer-selection.md)을 참고하세요.
