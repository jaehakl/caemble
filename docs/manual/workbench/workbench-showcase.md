# Showcase에서 예제 둘러보기

Showcase에서는 완성된 Experiment의 형상과 저장된 결과를 먼저 살펴볼 수 있습니다. 코드를 작성하기 전에 Caemble로 어떤 작업을 할 수 있는지 알아보기에 좋습니다. 둘러보는 동안 Workbench에서 편집하던 로컬 작업은 바뀌지 않습니다.

## 시작 페이지와 Showcase

`/`에 접속하면 로그인한 사용자는 `/workbench`, 로그인하지 않은 사용자는 `/showcase`로 이동합니다. 두 주소 모두 로그인 여부와 관계없이 직접 열 수 있습니다. 특정 저장 버전은 `/workbench?experiment=ID`로 열 수 있습니다.

Showcase에는 접근할 수 있는 저장 Experiment와 공개 Demo가 4:3 대표이미지 카드로 표시됩니다. 처음에는 대표 Demo가 선택됩니다.

1. 관심 있는 카드를 선택합니다.
2. 오른쪽 Viewer에서 형상과 결과를 살펴봅니다. 초기 화면에 고정된 Measurement가 있으면 해당 결과를, 없으면 가장 최근에 기록을 마친 Measurement를 표시합니다.
3. 소스를 살펴보거나 작업을 이어 가려면 카드 위쪽의 편집 버튼으로 Workbench를 엽니다.

> Showcase의 저장된 작업과 Catalog 예제는 용도가 다릅니다. 저장된 결과를 둘러볼 때는 Showcase를, 예제 소스로 내 작업을 시작할 때는 Workbench의 **New → Templates**를 사용하세요.

### 원하는 항목과 버전 찾기

이름·설명·key로 검색하고 Repository를 여러 개 선택해 목록을 좁힐 수 있습니다. 생성일·이름·Measurement 수로 정렬할 수 있으며 기본 순서는 최신 생성일순입니다.

같은 namespace·Repository·key에 속한 버전은 최신 버전 카드 하나로 묶입니다. 카드 오른쪽 아래의 버전 배지를 누르면 이전 버전을 선택할 수 있습니다. 생성일과 Measurement 수는 대표 버전 기준이며, 이전 버전의 수를 더하지 않습니다.

대표이미지가 없거나 불러오지 못하면 기본 이미지가 표시됩니다. 삭제 권한이 있는 카드에는 삭제 버튼이 나타납니다. 삭제할 때는 선택한 버전과 연결 데이터를 확인하세요. 다른 버전까지 한꺼번에 삭제하는 버튼은 아닙니다.

## Experiment 레이아웃과 불러오기

Workbench의 **Experiment** 탭은 왼쪽 Viewer와 오른쪽 코드 편집기로 나뉘며 기본 너비는 50:50입니다. 가운데 구분선을 드래그하거나 키보드로 포커스를 옮긴 뒤 방향키를 눌러 크기를 조절할 수 있습니다. 아래쪽 **Console**에서는 진행 상황과 오류를 확인합니다. 이 탭의 크기를 조절해도 다른 탭의 배치는 바뀌지 않습니다.

| 메뉴 | 사용 목적 | 작업에 반영되는 시점 |
| --- | --- | --- |
| **New → Templates** | 예제를 바탕으로 새 작업을 시작합니다. | 항목 선택 후 **적용**을 눌렀을 때 |
| **Showcase의 편집 버튼** | 선택한 저장 버전을 Workbench에서 엽니다. | 해당 버전의 Workbench로 이동했을 때 |

**Templates**에서는 이름·설명·Catalog 좌표·버전을 확인하고 검색할 수 있습니다. 항목을 선택해 내용을 살펴본 뒤 **적용**을 누르면 소스와 Calculation 정의를 함께 가져옵니다. 선택만 하거나 창을 닫으면 현재 작업을 바꾸지 않습니다. 저장하지 않은 편집이 있으면 적용 전에 교체 여부를 확인합니다.

저장된 작업을 열 때는 Showcase에서 카드와 버전을 선택해 형상·결과를 미리 보고 편집 버튼으로 이동하세요. 새 예제를 적용하는 일과 기존 버전을 여는 일을 구분하면 작업을 이어 가기 쉽습니다.

## 저장된 결과가 열리는 기준

저장된 Experiment를 열면 초기 화면에 고정한 Measurement를 불러옵니다. 고정 설정이 없거나 해당 Measurement가 삭제되었다면 가장 최근에 결과를 기록한 Measurement를 사용합니다. 직접 선택했거나 로컬 작업에서 복원한 Measurement가 있으면 그 선택이 우선합니다.

선택한 Measurement의 변수, 재료와 RecordedData를 함께 불러오며 광선 경로 등 지원되는 결과를 Viewer에 표시합니다. 기록된 결과가 없으면 Experiment만 표시합니다. 저장된 작업을 여는 것만으로 Solver가 자동 실행되지는 않습니다.
