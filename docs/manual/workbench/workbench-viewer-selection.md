# 3D Viewer에서 형상과 결과 살펴보기

Viewer는 형상과 계산 결과를 같은 공간에서 살펴보는 화면입니다. 먼저 전체가 보이도록 화면을 맞추고, 확인할 데이터를 고른 뒤 필요한 단면이나 성분을 선택해 보세요.

## 처음 사용할 때

1. **전체 맞춤**으로 현재 형상이나 결과가 화면에 들어오게 합니다.
2. 위쪽 Output과 타입별 Visualization에서 보고 싶은 결과를 고릅니다. Geometry는 항상 표시됩니다.
3. Output 목록 오른쪽에서 차트 종류·축·집계·채널·성분·범위를 조절하고, 공통 툴바의 **재생 제어**에서 재생 대상을 고릅니다.
4. 색의 의미는 범례로 확인하고, 다른 조건과 비교할 때는 필요에 따라 **값 범위 고정**을 사용합니다.

데이터의 값은 그대로 두고 표시 방식만 바꾸는 과정입니다. 현재 보기를 계산식으로 옮기고 싶다면 [Viewer 변환 코드 복사](workbench-calculation.md#viewer-변환-코드-복사)를 사용하세요.

## 형상과 면의 ID 확인하기

Solver가 적용될 형상이나 면을 찾을 때는 **Off / Geometry / Surface** 선택 모드를 사용합니다. 처음에는 **Off**로, 카메라 회전과 이동만 동작합니다.

| 모드 | 클릭했을 때 |
| --- | --- |
| **Geometry** | 가장 가까운 형상 전체를 강조하고 `starter.body`처럼 장면 전체에서 식별할 수 있는 경로를 표시합니다. |
| **Surface** | 해당 면만 강조하고 `starter.body/surface/1`처럼 면 번호가 포함된 경로를 표시합니다. |

선택 카드의 복사 버튼으로 Solver 그룹에 사용할 경로를 복사할 수 있습니다. **Focus**는 현재 카메라 방향을 유지하면서 선택한 형상이나 면에 화면을 맞춥니다. 빈 공간을 클릭하거나 **Clear**를 누르면 선택을 해제합니다. 마우스를 드래그하는 동작은 카메라 조작으로 처리하므로 이동 도중 선택이 바뀌지 않습니다.

선택한 경로의 정확한 문자열이 소스에 있을 때만 **Source 찾기**가 활성화됩니다. 한 곳이면 바로 이동하고 여러 곳이면 목록을 보여 줍니다. Viewer에서 선택하는 것만으로는 코드 탭이나 커서를 옮기지 않습니다. 선택 상태는 Draft나 URL에 저장되지 않습니다.

반대로 소스 편집기의 `geometryGroup`·`surfaceGroup` 경로에 커서를 두면 해당 대상이 Viewer에서 강조됩니다. 정적인 JSX `id="body"`에 커서를 두면 그 ID로 만들어진 현재 장면의 모든 인스턴스와 각각의 전체 경로를 보여 줍니다. 식을 포함한 템플릿 ID는 코드만으로 실행 경로 하나를 확정할 수 없으므로 Viewer에서 직접 인스턴스를 선택하세요.

## Viewer 도구모음

공통 도구는 위쪽 가로줄에, 데이터별 도구는 왼쪽 세로줄에 있습니다. 아이콘에 포인터를 올리면 기능과 현재 상태를 확인할 수 있습니다. 위쪽에서는 초기 화면·대표이미지, 전체 맞춤·X/Y/Z 카메라, 선택 모드, Task 표시와 Geometry·Output·타입별 Visualization을 설정합니다. Output과 각 Visualization은 ‘선택 안 함’을 포함한 단일 선택이며 서로 독립적입니다. Visualization 버튼은 해당 데이터가 있을 때만 나타납니다. 저장 설정이 없다면 타입마다 첫 유효 항목을 표시합니다. Viewer는 데이터 유무와 관계없이 위 3D / 아래 차트로 나뉩니다. 초기 높이는 절반씩이며 분할선으로 조절합니다. 위아래는 같은 Output을 사용하며 채널·성분·시간·주파수 집계와 값 범위를 공유합니다. 차트 표시 축은 3D 공간 배치를 바꾸지 않습니다. **재생 제어**와 **변환 코드 복사**도 공통 툴바에 있습니다.

Output과 mesh-field 메뉴는 선택과 설정을 조작하는 동안 열린 상태를 유지합니다. 인덱스·시간·투명도·값 범위처럼 연속해서 조절하는 패널은 Viewer 위에 표시되어 화면 크기를 바꾸지 않습니다. 같은 아이콘을 다시 누르면 닫힙니다. 인접한 패널은 겹치지 않게 배치하며 공간이 부족하면 스크롤합니다. 별도의 Viewer 확장과 하단 표본 조회는 제공하지 않습니다.

## Output 시각화

Box Grid는 상자 모양의 격자에서 관측한 수치 결과입니다. 결과가 여러 개라면 처음에는 공간 격자 수 `nx × ny × nz`가 가장 많은 유효한 Box Grid를 우선 표시합니다. 시간·주파수·성분 수, 실제 부피와 형상 겹치기 가능 여부는 이 순위에 영향을 주지 않습니다. 동률이면 목록의 첫 항목을 고르며, 유효한 Box Grid가 없다면 다른 결과의 기본 선택 규칙을 사용합니다. 사용자가 고르거나 복원한 결과, 이미 자동 선택한 결과는 이후 갱신에도 유지합니다.

상단 Output은 **XYZ point cloud → 공간 Heatmap → 미표시** 순서로 지원 여부를 판단합니다. XYZ 위치가 있으면 공간축과 표현을 고정하고, 평면 배치만 지원하면 Heatmap을 사용합니다. 아래 차트는 Line Chart와 Heatmap을 선택할 수 있습니다. 기본 주축은 가장 긴 축, 보조축은 다음으로 긴 축이며 동률은 x/y/z/t/f 순서로 정합니다. 길이가 1인 축도 포함하므로 모든 축의 길이가 1이면 1×1 Heatmap으로 시작합니다. 진동 가능한 복소수 결과는 **공통 시간 t=0**을 보여 주고 자동 재생하지 않습니다. 실수 또는 0 Hz만 있는 결과는 정적으로 표시합니다.

아래 차트에서 Heatmap을 선택하면 Output 패널의 Heatmap 버튼 옆 **정사각 픽셀** 토글로 표시 방식을 바꿀 수 있습니다. 기본값은 켜짐이며, 각 셀을 같은 크기의 정사각형으로 그려 차트 영역에 맞춥니다. 끄면 차트 영역을 채우고 셀의 크기에 실제 축 좌표 간격을 반영합니다. 선택은 결과별로 저장됩니다.

Output 오른쪽은 차트 종류 아래 **x, y, z, t, f → Amplitude/Phase/시간 전개 → comp → 값 범위** 순서입니다. 채널에서는 값·진폭·위상·시간 전개를 고르고, 시간 전개에서는 현재 시각을 초(s)로 지정할 수 있습니다. 성분에서는 개별 성분과 벡터·텐서 크기를 고릅니다. 위상(Phase)을 볼 때는 성분 하나를 선택합니다.

### 축과 집계 고르기

각 축 행에서 가로 양쪽 화살표는 주축, 세로 양쪽 화살표는 보조축을 선택합니다. 주축은 Line Chart의 X축과 Heatmap의 가로축이고, 보조축은 Line Chart의 여러 선과 Heatmap의 세로축입니다. 반대 역할에 있는 축을 선택하면 두 축을 교환합니다. Line Chart는 보조축을 해제할 수 있습니다.

표시하지 않는 축에는 **mean·sum·min·max·median·std·개별 index**를 선택합니다. 개별 index를 고르면 같은 행에 슬라이더가 나타납니다. 선택한 index의 실제 좌표·단위와 나머지 축의 집계 방법은 패널을 닫아도 차트 상단에 표시됩니다. 주파수 표시 단위가 지원되는 결과는 f 행에서 nm/Hz를 바꿉니다.

### 형상 겹치기와 색상 범위

Geometry는 항상 표시하며 불투명도는 **90% ↔ 50%**로 바꿉니다. 같은 source/Vars의 변형 mesh와 원래 Geometry를 함께 표시해 비교합니다. source/Vars가 다르거나 비교 정보가 없는 공간 결과는 선택을 유지하고 제외 이유를 안내하며, 아래 차트는 계속 표시합니다. 원형 mesh 윤곽 비교 옵션은 제공하지 않습니다.

Heatmap은 남은 공간축에서 선택한 인덱스의 평면에 표시합니다. 그 축을 집계했다면 Box의 중앙 평면을 사용합니다. 공간 좌표에는 Box 변환과 길이 단위를 적용합니다. 시간(t)이나 주파수(f)를 표시 축으로 쓰는 차트는 아래 영역에 표시합니다. ray·mesh-field·mesh-transform·particle-set은 타입별 메뉴에서 각각 선택합니다. 공간 데이터는 실행 이력과 좌표계가 호환될 때 같은 3D 장면에 표시하며, 호환되지 않는 항목은 선택을 유지하고 표시할 수 없는 이유를 안내합니다.

Output 패널 마지막의 **값 범위 고정**을 켜면 최솟값, 색상 막대(colorbar), 최댓값 입력이 열립니다. 같은 아이콘을 다시 누르면 자동 범위로 돌아갑니다. 색상 막대는 다른 위치에 중복 표시하지 않습니다. 최솟값과 최댓값이 같은 상수 범위도 지원하며, 잘못된 값을 입력하는 동안에는 마지막 유효 범위를 유지합니다.

### 시간에 따른 변화 재생하기

공통 툴바의 **재생 제어**에서 결과 이름별 대상을 선택합니다. Box Grid의 t축은 길이가 2 이상일 때 나타나고, t가 차트의 주축이나 보조축이면 선택할 수 없습니다. 진폭·위상 채널이 있으면 시간 전개를 선택할 수 있으며 양의 주파수가 없으면 재생할 수 없는 이유를 표시합니다. 변위 이력, 강체 운동, 입자 운동도 데이터가 있을 때 목록에 나타납니다.

한 번에 한 대상만 재생하며 대상을 바꾸면 이전 재생이 멈춥니다. 슬라이더, 이전·다음 프레임, 재생·일시정지, 반복과 속도를 조절할 수 있습니다. 패널을 닫아도 재생은 계속됩니다. 비교 화면에서는 하나의 패널로 같은 결과의 양쪽 Viewer를 제어합니다.

채널의 **시간 전개**는 진폭과 위상을 이용해 각 주파수의 값을 `A_f,c*cos(φ_f,c+2πf t)`로 계산합니다. 주파수 축의 sum/mean은 성분별 값을 합성한 뒤 벡터 크기를 구합니다.

시간과 재생 구간은 초(s)로 표시합니다. 기본 구간은 선택한 최저 양의 주파수의 한 주기입니다. 최고 주파수 한 주기를 20프레임으로 나누어 약 2초에 재생하며 계산이 느리면 재생도 느려집니다. 속도와 반복을 조절할 수 있고, 재생 중에도 값 범위와 카메라를 유지합니다. 비교 Viewer는 양쪽 주파수를 고려한 재생 구간과 공통 시간을 사용합니다.

### 메쉬와 점 표시 읽기

mesh-field 메뉴에서 Mesh 경계선, 구속/하중, 단면 축·위치, 변위 결과와 변형 표시를 조절합니다. 설정을 조작해도 메뉴는 열린 상태를 유지합니다. 성분·주파수·위상은 왼쪽에 있고, 시간 이력은 공통 툴바의 **재생 제어**에서 선택합니다. 변형은 항상 **실제 크기 1×**로 표시하며 과거에 저장한 확대 배율은 적용하지 않습니다.

3D Viewer에는 바닥 격자와 원점 축선을 표시하지 않습니다. 왼쪽 아래 **Scale bar**는 카메라 중심 깊이에서의 길이를 나타내며 확대·축소와 창 크기에 맞춰 바뀝니다. 시간·주파수 축 차트는 아래 영역에서 확인합니다. Mesh-field는 툴바와 범례를 제외한 영역을 채웁니다.

3D Point cloud는 변환·집계한 값이 정확히 0인 표본을 숨깁니다. 점의 면적은 값의 절댓값에 비례하며 가로·세로는 최대 10 CSS px입니다. 표시할 표본 수를 제한하기 전의 전체 데이터로 크기를 정규화하고, 재생 중에는 전체 재생 구간의 기준을 고정합니다. 색상 범위를 바꾸어도 점 크기는 달라지지 않습니다.

방향 성분은 상쇄되었지만 표시값이 양수인 화살표 표본은 점으로 나타냅니다. 숨긴 0값도 집계와 복사 데이터에는 남으며 Heatmap에서는 표시됩니다. Calculation의 3차원 결과에도 같은 점 표시 규칙을 적용합니다.
